# GPTCraber 🦀

把 AI 对话导出为 Markdown 的油猴脚本（Tampermonkey / Violentmonkey）。目前支持 **ChatGPT**、**豆包**、**DeepSeek**、**通义千问**、**Gemini** 五个平台，各是一个独立脚本。

导出结果为结构化的 Markdown，适配文本、代码、图片、引用等多种消息类型，图片尽量保存到本地，不再依赖会失效的网络链接。

## 功能

### ChatGPT 导出（chatgpt-md-exporter）

- 勾选当前会话的回合导出，每回合一个 md；只选一轮且没有上传文档时直接导出单个 md
- 拉取历史会话列表，按需勾选后批量导出，打包 zip（含图片与上传文档）
- 近 7 / 15 / 30 天快捷筛选与自定义日期区间
- 按项目（Projects）筛选会话
- 列表带本地缓存：10 分钟内切页不重复拉取，需要最新数据时点右侧刷新
- 设置中心：左侧导航分「会话列表 / 功能开关 / 侧边聊天 / 连接设置 / 文件夹同步 / 会话备份」六页
- 备份在后台跑：点「开始备份」后可以关掉整个对话框，右下角悬浮胶囊继续显示进度，完成后点一下直接跳回备份记录
- 备份范围的选择器带「重新获取」：缓存里的列表过期时可强制重拉，勾选不丢
- WebDAV 同步与备份：文件夹结构可双向同步；会话可整份导出为 zip 直接上传
  WebDAV，远端按「账号名 / 日期」分目录，多个 ChatGPT 账号互不覆盖，支持增量与全量
- 文件夹同步同样按账号隔离：远端文件名带账号名（`craber-folders.<账号>.json`），
  同一台 WebDAV 上多个账号的文件夹结构按账号分别存放，互不覆盖
- 侧栏文件夹：自行建文件夹，把项目与会话归类进去（条目可同时属于多个文件夹）
- 添加对话框支持搜索标题、近 7/15/30 天与自定义日期筛选，可批量勾选
- 拖拽归类：把侧栏的项目或会话拖到文件夹上即可加入；文件夹内条目可拖动调整顺序
- 文件夹内条目的更多操作复用原生菜单（重命名、置顶、分享、归档、移出等）
- 项目 / 会话菜单里可直接导出：会话导出为 Markdown，项目导出为其下全部会话的 zip
- 左侧导航轨道：节点跳转、悬停预览、键盘导航、跨长会话跳转，支持全量搜索定位
- 消息内大纲：长回复按 Markdown 标题抽出二级节点；全部节点列表保持简洁，悬停或键盘聚焦节点后，在独立气泡卡片中查看大纲并跳转到小节
- 项目内对话：顶栏显示项目对话入口，点会话名即可在本项目内切换对话
- 顶栏增强：半透明毛玻璃背景，长正文滚过时不与顶栏文字重叠
- 🦀 菜单内可单独关闭「节点导航」「项目 UI 优化」
- 单条回复导出：回复栏的 🦀 按钮，点一下导出这一条（自动带上对应的提问）
- 上传的 PDF、DOCX、TXT 等文档保存到本地，md 中以相对路径引用
- 回复中生成的图片、Word、PDF、代码等 `sandbox:` 文件随 ZIP 保存到 `images/` 或 `files/`，按原会话与消息下载；同名文件分别保存
- 附件/图片拿不到（403、过期等）会自动跳过并在结束时汇总提示，不会静默丢文件
- 静态 GenUI 卡片转换为文字；动态模板保留为折叠原文，代码围栏、行内代码、C++ 尖括号与公式保持原样
- 标题、嵌套列表、链接、写作块和表格转换为 Markdown；Chart 的静态数据转成表格，静态 SVG 示意图随图片保存
- 卡片内的生成文件链接也会收集下载；图片组件使用实际地址或可匹配的引用，缺少图片地址、关闭图片导出和 HTTP 下载失败分别标注
- 工具请求与结果遵循「导出工具」开关；引用替换核对原文标记，防止错位索引删除正常正文
- 兼容多种消息结构：parts 字符串 / 对象式 part / content.text / 平铺 items、linear_conversation，缺 content_type 也能导出
- 消息内大纲可单独关闭（功能开关 → 消息内大纲），关掉后节点卡片与面板只保留回合级节点
- 输入框清除格式：在 ChatGPT 输入框「＋」所在工具区点橡皮擦按钮，将当前草稿的代码块、标题、加粗等转成普通文本，保留文字、换行和代码缩进；可在功能开关中关闭
- 备份页重排：位置 / 范围 / 执行方式分段成卡，操作栏前置，历史列表加高
- 会话备份支持按「项目会话 / 独立会话」分别开关，可整类不备份
- 「锁定项目展开」只挡系统自动展开；手动点击/键盘展开始终生效（按项目名豁免，不靠猜触发者）
- 导出前可预览渲染后的 Markdown
- 可选：问答对 / 仅 AI 回复、是否导出工具代码、是否附参考来源、图片是否内嵌

### 侧边聊天

在 ChatGPT 页面右侧开一栏与主对话**并行**的问答线，用你自己的 OpenAI 兼容模型接口回答。

- **占位式分栏**：打开时顶栏与正文一起往左缩，面板占据让出来的位置，
  不会盖在正文上面；关闭后恢复原样。宽度可拖左边缘调整
- **开合与宽度都会被记住**：刷新页面、切换会话后自动回到上次的状态；
  在设置页这类非会话页不会弹出面板，但记忆保留，回到对话里会恢复
- 入口：顶栏 🦀 右边的对话气泡按钮（首页与项目页也显示，不要求已进入某个对话）；
  或 `Ctrl+Shift+K` 开合；或在正文里选中一段文字后点浮出的「在侧边问」
- 在输入框左下角菜单点击「主会话」整行，打开子菜单，开启「附带主会话」并选择上下文范围：
  - **当前轮**（默认）：选中区域所属轮次的完整问答；未选中时取最近一轮
  - **整个对话**：读取当前分支的完整问答，包括虚拟滚动未显示的消息
  主会话完整保存为 `.txt` 附件，只随当前提问发送，重试时复用同一份快照。
  文件通过 `/responses` 发送；网关明确不支持时提示并回退到 `/chat/completions` 的完整文本。
  文件输入仍受所选模型的上下文窗口和接口大小限制，脚本不再按 12,000 字符截断。
- 流式输出（逐段显示），可随时「停止」；每条回复可复制、可重试，用户消息气泡悬停后也可复制
- 实时流式输出：模型每次返回正文增量后直接进入回复，界面只把 DOM 更新合并到浏览器绘制帧；
  不额外延时播放或改写模型返回节奏
- 面板采用轻阴影用户气泡、整宽助手正文、默认折叠的思考过程，
  模型信息与输入框收进底部浮起的圆角输入卡，深色主题同步适配
- 输入卡左下角九宫格打开「附件 / 主会话」菜单，底部模型名称打开模型与思考深度菜单；
  思考滑块带档位圆点，松手后吸附到所选档位，长模型名支持悬停查看
- 「附件」支持图片、PDF 和文本文件，可预览、移除，发送后保留在对应消息中，重试时一并带入
- 思考过程收成「思考7s ›」一行，点开显示带竖线的推理正文和独立滚动区
- 输入区按聊天习惯操作：**Enter 发送、Shift+Enter 换行**（也兼容 Ctrl/Cmd+Enter），
  中文输入法选词时的回车不会误发送；首个字到达前显示等待动画
- 流式解析兼容较宽的网关差异：`content` 为数组/对象、缺少 `choices`、
  只触发 `onload` 的"秒回"响应（数据全在 `response.stream` 里）都能正常出字
- **推理模型适配**：思考内容（`reasoning_content` / `reasoning` / `thinking` /
  `reasoning_details`）单独收进折叠容器，流式期间显示「正在思考…」并实时增长，
  默认收起，手动展开后保持用户选择
- **思考等级**在「侧边聊天 → 可用模型 → 模型配置」对话框中逐项勾选启用：关闭 / 低 / 中 / 高 / 最高，
  分别发送 `reasoning_effort` 为 `off` / `low` / `medium` / `high` / `max`。
  主会话文件使用 Responses 时，改为 `reasoning.effort`，关闭和最高分别映射为 `none`、`xhigh`。
  侧栏滑块仅显示启用的档位；全部取消则隐藏思考深度，未指定等级时不发送推理参数
- 各模型独立保存侧聊历史、主会话开关与范围、文本/图片输入模态、思考等级。切回模型时恢复其对话。
  关闭图片输入会禁用图片与 PDF，关闭文本输入会禁用文字与文本附件，也不会附带主会话正文。
- **未配置时面板里直接给引导**：消息区显示「还没配置模型」卡片 + 「去配置」按钮，
  点一下直达设置页；卡上还列了常用接口地址（DeepSeek / OpenRouter / OpenAI / Ollama），
  点一下复制。未配置时输入框与发送按钮是禁用的，配好保存后自动恢复
- 接法：设置中心 →「侧边聊天」，填 API 地址（通常以 `/v1` 结尾）和所需的 Key。
  常见后端：DeepSeek `https://api.deepseek.com/v1`、OpenRouter `https://openrouter.ai/api/v1`、
  OpenAI `https://api.openai.com/v1`、Ollama 本地 `http://127.0.0.1:11434/v1`
- 点「获取模型」从接口 `/models` 读取候选，选择需要的模型后点「添加模型」，再保存配置。
  接口未提供候选时也可手动输入模型 ID。候选不会自动出现在侧栏模型菜单里。
- 侧栏的对话只存在本机，**不写进 ChatGPT 的会话列表**，也不消耗 ChatGPT 账号额度
- 功能开关里可单独关掉「侧边聊天」与「选中文字时浮出入口」

### ChatGPT 公式渲染（chatgpt-latex-smart-fix）

- 把正文里没渲染出来的 LaTeX 公式就地渲染好，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`
- 会先判断 `$...$` 里的内容是否真的像公式，`$100`、`$29.9` 这类金额照常显示，不会被误渲染
- 代码块、行内代码里的内容不动
- 只做渲染、不导出，与导出脚本互不影响，两个可以同时装

### 豆包（doubao-md-exporter）

- 勾选回合导出、多会话批量导出、日期筛选、导出前预览
- 思考过程可选导出
- 单条回复导出：回复栏的 🦀 按钮
- 图片保存到本地

### DeepSeek（deepseek-md-exporter）

- 勾选回合导出、多会话批量导出、日期筛选、导出前预览
- 思考过程可选导出
- 图片平台不提供下载地址，只能记录文件名，不下载

### 通义千问（tongyi-md-exporter）

- 勾选回合导出、多会话批量导出、日期筛选、导出前预览
- 思考过程可选导出
- 图片保存到本地（你上传的图与 AI 生成的图）
- 联网搜索的配图保留原始链接

### Gemini（gemini-md-exporter）

- 勾选回合导出、导出前预览、单条回复导出、图片保存到本地
- 只针对当前打开的会话，不做多会话批量导出与日期筛选（引擎限制）
- 长会话需先滚动到顶部把内容加载出来，已加载的回合才能导出

### 抓包工具（craber-sniffer）

- 面向开发者的辅助脚本，用于分析新平台的数据结构，普通用户不需要装
- 分析完即可卸载

## 支持的消息类型

- 纯文本、Markdown、代码块
- 图片（ChatGPT / 豆包 / 通义千问 / Gemini 保存到本地；DeepSeek 仅记录文件名）
- 附件（ChatGPT 上传的非图片文档保存到本地；Gemini 记录上传文件的名称与类型）

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 点上表里对应平台的「安装」链接 —— 油猴会识别 `.user.js` 并弹出安装页面，确认即可。
3. 打开对应网站：ChatGPT 的入口是顶栏右侧的 🦀 按钮；其余平台是右下角的「会话列表 / 导出当前」按钮。

各脚本头部都配置了 `@updateURL`（与上方脚本表中的安装链接一致，指向本仓库 `main` 分支同名文件），油猴会定期检查更新，有新版本时自动提示升级。

| 入口 | 作用 |

| 输入框「＋」所在工具区的橡皮擦（ChatGPT） | 清除当前草稿的 Markdown 富文本格式，保留文字与换行，不发送消息 |

### 输入框清除格式（ChatGPT）

- 处理整个当前草稿，适用于首页、新对话和已有会话；不修改历史消息或上传附件。
- 清除的是已经渲染的格式，不是还原 Markdown 源码，也不会删掉代码里的 `*`、`#`、下划线或反引号；链接保留可见文字。
- 清除后可继续编辑，撤销使用编辑器原生的 `Ctrl+Z`（macOS 为 `⌘Z`）。不同编辑器版本的草稿同步与撤销行为需在真实浏览器中验证；若提示未接受操作，请先检查草稿。
- 中文输入法组合输入期间不执行。编辑区内若含无法无损处理的附件、提及或其它非文本节点，会提示并保留原稿；普通上传附件所在区域不受影响。
- 默认开启，可在 🦀 → 功能开关 → **输入框清除格式** 中关闭，立即移除按钮并记住选择。

🦀 菜单「功能开关」中可独立关闭界面增强，包括：

| 开关 | 关闭后的效果 |
| --- | --- |
| 节点导航 | 撤掉左侧回合节点轨道，不再拉取会话结构 |
| 项目 UI 优化 | 撤掉顶栏里项目对话入口与当前位置，不再拉取项目接口 |
| 输入框清除格式 | 撤掉输入框工具区的橡皮擦按钮并移除对应监听 |

### ChatGPT 页面结构诊断

侧边聊天的占位布局依赖 ChatGPT 当前的页面壳结构。需要排查官方改版或窄屏适配时，可临时安装
[`tools/chatgpt-layout-probe.user.js`](tools/chatgpt-layout-probe.user.js)。它只采集布局骨架、
关键容器的尺寸与样式，不读取聊天正文；点「测让位」还会逐个尝试候选容器并自动还原。

建议依次捕获四种状态，然后导出 JSON：

1. 原生左侧栏展开、Craber 侧边聊天关闭
2. 原生左侧栏收起、Craber 侧边聊天关闭
3. 原生左侧栏展开、Craber 侧边聊天打开
4. 窗口缩到约 1024px 宽，再重复第 2、3 种状态

切换状态时不要刷新页面，否则探针内存中的快照会丢失。诊断完成后即可卸载此脚本。

## 说明

- 会话导出在本地浏览器处理。使用侧边聊天时，问题、附件和启用的主会话上下文会发送到你配置的模型接口；使用 WebDAV 同步或备份时，相应数据会上传到你配置的 WebDAV 服务。
- 依赖各平台前端结构，官方改版后可能需要适配。
- Gemini 版只覆盖当前打开的会话，且只有页面上已加载出来的回复才能导出，很长的会话记得先滚动到顶部。
